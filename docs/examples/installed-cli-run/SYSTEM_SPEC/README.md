# 本地 Skill 包静态预检查

版本：1.0。状态：最终规格套件（声明范围内）；尚未实现目标工具。面向有本地文件读取和命令执行能力的开发者、Agent 及其发布流程。目标是发布前发现确定性的编码、元数据和引用问题，并提供可定位的诊断；不负责修复或发布。

依次阅读 [行为规则](RULES.md)、[命令与运行契约](CONTRACT.md)、[验收场景](ACCEPTANCE.md)。本文决定范围，RULES 决定检查语义，CONTRACT 决定接口与生命周期，ACCEPTANCE 是对前述规则的验证，不新增规则。

## 范围

检查一个或多个本地目录，递归扫描小写 `.md` 后缀文件；对精确命名的 `SKILL.md` 检查 YAML 元数据，对所有扫描到且能解码的 Markdown 检查限定语法的引用是否存在，输出 Skill 大小概览、警告、错误和退出码。此工具没有图形界面、账户、网络服务或持久化状态。

预检查通过仅表示本规则集未发现 ERROR：不保证存在 Skill，不保证全部 Markdown 链接有效，不保证官方格式合规、宿主可加载、触发质量、语义正确、安全或可发布。空输入目录会得到零计数的成功结果。发布产品若要求至少一个 Skill，须自行验证该前置条件。

明确排除：内容蒸馏、编译、Capability Bundle、增量更新、补丁、快照、回滚、锁、staging、发布、Registry、浏览器投稿和 ZIP；不纳入投稿特有的 20 MB 限制、疑似密钥文件名筛选、忽略文件清单、README 建议与大小写不敏感的 Skill 计数。也不执行包内脚本、调用模型、检查远程链接或 Markdown 锚点。

## 环境与依赖闭合

本次样例的支持范围限定为本地 POSIX 文件系统及 UTF-8 终端；Windows 路径和网络文件系统未验证。来源实现和本次调查使用 Python 3.12 + PyYAML 6.0.3，这不是新工具的必装依赖。实现语言和解析库可选，但必须复现下述可观察语义。

| 依赖 | 处理与完整边界 |
| --- | --- |
| 身份、权限 | 由目标环境提供进程身份和文件读取/目录枚举权限；无提权、授权登录或权限修改。权限失败按 CONTRACT 返回未完成。 |
| 数据 | 纳入：目录、Markdown、YAML、路径存在性；无 Registry、书籍源或中间编译数据依赖。 |
| YAML | 纳入：RULES 定义的安全加载语义；可使用等效解析器，不要求 PyYAML。具体实现若有外部运行库，由目标产品提供；缺失时按 CONTRACT 报告运行失败，不自动联网安装。 |
| 配置 | 纳入：仅位置参数；无配置文件、环境变量开关、忽略列表、严格模式。 |
| 状态/事件 | 纳入：每次调用独立的内存计数和诊断，stdout/stderr 与进程结束是唯一输出。 |
| 发布衔接 | 目标发布流程提供稳定的待检目录，使用退出码；是否接受 WARN、是否要求非零 Skill 数由其已有策略决定。预检查不调用发布接口、不改变发布状态。 |
| 恢复 | 使用者修复文件或权限后整次重跑；无自动修复、增量缓存、回滚。 |
| 资源与隔离 | 宿主控制进程预算与文件可见范围；相对路径和文件符号链接可以指向输入根以外，本工具不是文件系统沙箱。 |

必要设计约束是确定性规则、只读行为、诊断完整性与退出码；内部模块划分、打包方式可以变化。任何改变成功/失败结果的规则扩展应使用新版本，不得作为隐藏默认项加入。
