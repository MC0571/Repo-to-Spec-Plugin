# 本地 Skill 触发评测确定性工具规格

本套件定义维护者使用的三个本地命令：从 suite 生成训练/验证 ID 划分、生成隐藏预期字段的任务包、根据外部逐例选中结果生成 Markdown 评分报告。报告用于阅读，不定义通过门槛、发布决定或统计非劣结论。规格版本为 1；本文与下列文档共同构成规范，不需要来源仓库或调查记录。

阅读顺序：

1. [接口与工作流](CONTRACT.md)：输入、输出、默认、文件副作用、失败恢复和依赖。
2. [划分算法](SPLIT.md)：跨实现一致的随机顺序与切片。
3. [评分规则](SCORING.md)：计数、逐例判定和报告格式。
4. [验收](ACCEPTANCE.md)：可直接构造的测试向量及预期结果。

CONTRACT 是数据和操作的权威，SPLIT 是划分的权威，SCORING 是评分的权威；验收不得另增约束。实现语言、框架、内部模块与操作系统自由选择，但必须保持这些可观察行为。本文中的 `trigger-eval` 是独立实现的逻辑命令名，启动器和安装包装可替换，不要求 Python、特定宿主、仓库目录或网络服务。

术语：suite 是持有预期答案的本地 JSON；case 是其中一次提示的定义；run 是外部结果行上的标签，不是评分器执行的一次模型调用；target 是被评测 Skill 标识；sibling_target 是期望选中的兄弟 Skill 标识；train/validation 是同一次乱序的两个连续片段。`none` 是普通字符串，与 JSON null 不同。

维护者负责提供 suite、技能标识清单、外部结果与输出位置，并阅读产物。命令以调用进程身份读写，无内部账号、提权或额外授权层。外部执行者只接收任务包并提供结果文件；命令不验证其身份、模型版本、执行次数、理由或记忆隔离。

纳入 JSON 文件读写、确定性乱序、任务包字段筛选、结果匹配与汇总、终端反馈。排除真实 Skill 选择器、Skill 安装和内容读取、调优、蒸馏、编译、更新、输出质量评测、版本选择、发布及新阈值。无图形 UI、后台服务或任务队列；交互全部是同步命令、文件和终端。

特别保留：评分不会检查计划 run 是否齐全；重复行重复计数；未知 case 不分类但仍进入 runs；兄弟案例选错其他非目标 Skill 仍计 TN。成功退出只表示命令完成，不表示评测完整、正确或通过。不得以“修复数据质量”为由改变这些规则。
