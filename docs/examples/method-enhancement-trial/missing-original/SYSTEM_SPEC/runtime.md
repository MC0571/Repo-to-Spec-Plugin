# 运行与数据契约

本章是从真实、完整、可审计评测约束推导的核心设计。它补足来源确定性工具，不声称目标宿主已支持接口。不在此设置业务通过阈值。

## R-1 冻结输入与计划集合

评测管理员创建不可变 evaluation_id，绑定 suite 原文及切分版本、集合类型、候选包快照和运行配置。用例 ID 唯一且非空；prompt 为字符串；target 为非空且非 none 的实际候选 ID；候选 ID 唯一，none 为保留值。sibling 必须提供不同于 target 的有效候选 sibling_target。train_ratio 是 [0,1] 内有限数，runs 是正整数，正式评测至少 3；不合规则 input_invalid。来源兼容诊断可测试其他输入，但不得作为正式运行。

case_id 是不透明数据，文件名应编码或使用内部 ID，禁止路径逃逸和覆盖任意文件。对未参与选中子集的用例不安排运行。计划工作集合 P 为本次子集每个 case_id 与 1..runs 的笛卡尔展开；manifest 存储 P，planned = |P|。空子集标 empty，不能得到完整评测结论；需更换 suite 或切分配置后新建评测。各类别覆盖数和实际缺类必须在报告可见，缺类的指标零值不证明性能。

suite 原文、答案、切分清单与机器计划由管理员保存；执行方仅得到去答案的任务视图。准备之后不允许悄悄改输入；任何语义变化必须建立新 evaluation_id。

## R-2 结果归集、完整性和匹配

执行器每次返回与 evaluation_id、case_id、run、attempt_id 绑定的结果。selected_skill 必须是冻结候选 ID 或 none；多选、无法解析、未知 ID、缺字段、null 均为结果无效，不能转换成正常 none。真实“未选择”只由有效响应 none 表示。记录正常结果或 error，保留原始响应供有权审计者查看。

归集器以 (evaluation_id, case_id, run) 为唯一槽位：同一 attempt_id 的同内容传输重送是幂等确认，不增计数；不同内容或新执行重复占槽记 conflict，不能挑有利结果。与 P 不匹配的结果记 unexpected；其他版本或批次结果拒绝进入。来源 JSONL 导入没有 attempt_id 时，重复行直接记 duplicate，不擅自推定是网络重送。

仅当 P 非空、每个槽位恰有一个有效成功结果且不存在未解决的 unexpected/duplicate/conflict，整轮才能 completed。报告同时列 planned、received（原始接收数）、valid_unique、missing、invalid、duplicate、unexpected、conflict 和 execution_error。缺失不得被从计划分母移除。原始评分可在不完整时展示，但明确为 provisional，不赋予最终效力。

有效结果按 S-4 计数，并额外记 expected_match：正例必须选择 target；负例与 edge 必须不选 target；sibling 必须恰好选 sibling_target。相应逐例标签为 matched/mismatched。兄弟选错其他候选或 none 必须显示 mismatch，同时保留原始 TN。报告分开显示各 expected 类别的计划、有效、匹配和不匹配数；不得仅显示总体 F1 掩盖特定类别错误。多次运行不归并成一次“用例通过”；业务对这些运行如何聚合由 U-3 确定。

## R-3 真实选择、隔离与保留集

管理员以候选包冻结快照配置真实宿主选择环境。每个运行使用干净上下文，无前一用例、前次重复、调优历史和答案。并发可用，但环境不能相互污染；预算和模型采样参数须固定记录。执行器不得擅自删掉竞争 Skill。每个调用必须在“选择完成”边界停止，不执行被选 Skill 的实际任务；若宿主只能边执行边选，U-1 未闭合，不能声称已实现此契约。

选择器输入仅含 prompt、候选的真实可见表示和真实宿主必要上下文。内部调度 ID 可作为外部关联字段，不能将含答案的 case 名称或文件路径暴露给模型。隐藏 expected、notes、sibling_target、阈值、主流程意见与验证集标签。避免通过文件权限、检索上下文、共享日志或记忆绕过隔离。真实宿主实际还读取哪些资源必须由 U-1 列清，不能仅仿造一段“你会选哪个”的模型提示就称真实选择。

训练集逐例诊断可给维护者。保留集的输入、答案及逐例结果由管理员和发布审核者受控访问；维护者只得到聚合结果与有效性状态。如果向其披露失败细节或用于改 Skill，标记该集合 exposed 并转回归集；下一轮验收必须使用未参与调优的保留材料。选版可由受控评测方比较已冻结候选版本，不得把反复调整后的材料继续标未见。具体身份系统、保留时长和部署权限由 U-4/U-5 核实，不能假设目标已经隔离。

## R-4 状态、失败与恢复

| 状态/触发 | 所有者与反馈 | 恢复 |
| --- | --- | --- |
| created → input_invalid/empty | 管理员校验失败，列字段或空集合原因；不调用选择器 | 修正后新建 evaluation_id |
| created → blocked | 必需提供者或配置缺失，列 U 编号 | 补齐并核实后创建运行 |
| created → prepared → running | 管理员提交计划；执行器逐槽运行；显示 valid_unique/planned | 运行中不能宣称通过 |
| running → incomplete | 超时、调用错误、缺失、无效、重复冲突或进程中断；保留诊断 | 本版本采用整轮新建评测，不补抽有利样本，不混入旧结果 |
| running → cancelling → cancelled | 协调器先请求停止，执行器确认停止或隔离后结束；期间不提交最终报告 | 新轮执行；旧轮迟到数据隔离记录 |
| running → completed | 归集校验完整后，评分器一次提交完整报告及有效性绑定 | 终态不可修改；修改输入产生新轮 |

崩溃后若不能证明完整提交，视为 incomplete；旧报告与临时报告不能自动复用。一次执行超时不得推定 none。未核实选择边界无副作用前，不启用自动重新调用。发布动作不在评测器中；评测取消不代表既有系统发布回滚。

没有统一来源时限。目标方需提供调用超时、总预算、取消能力和资源限制；这些值缺失时真实执行配置不完整，但核心状态规则仍可实现。不规定吞吐量或准确率 SLA。

## R-5 报告与有效性

机器报告的最小逻辑结构（传输可用文件或目标 API，不要求特定数据库）：

| 字段 | 内容 |
| --- | --- |
| report_version | 1 |
| evaluation_id / target / set | 不可变身份、目标、train/validation/all |
| execution_kind | real_selector / synthetic / fallback；后两者不可冒充 real_selector |
| evaluation_state | R-4 状态 |
| provenance | 包摘要；全部候选 ID、顺序、可见元数据及内容摘要；suite 摘要；切分清单摘要；计划；宿主、模型、选择器/适配器版本；提示模板、工具、权限、采样参数、随机配置、预算与隔离配置；评分规则版本；开始结束时间 |
| integrity | R-2 所有计数与错误清单 |
| metrics | S-4 计数、原始比率和三位展示值；另按类别统计 expected_match |
| rows | 按计划顺序的逐运行原始选择、判定、匹配、错误；受 R-3 访问控制 |
| exposure | 保留集是否 exposed、原因与时间 |
| decision | 本能力没有业务决策时为 not_evaluated；不得用 completed 替代 allow |

完整报告只有在所有数据写成后提交一个完成标记或原子发布引用；消费者只读已提交的快照。人类报告显示状态、计划/有效数量、类别错误、指标及未决原因，与机器内容一致。源 Markdown 的 runs/退出码只适合诊断，不能替代本结构。

报告产生后，包内容、竞争集合或顺序、suite/切分、真实选择配置、宿主/模型/工具/权限、规则或运行预算改变，都不能仅凭旧文件名或包摘要复用结果。报告记录实际有效性输入，消费者与本次发布上下文逐项匹配。无法取得稳定模型或配置版本时标为不可验证有效性，不声称可复用。

发布策略另有 policy_id/version 和预注册时间，决策绑定报告 ID 与策略摘要。策略变化不改历史观测，但旧决定失效；是否允许用旧报告重判以及报告最大年龄由 U-4 预先定。无策略时 decision 保持 not_evaluated，不能签发批准。

## R-6 所有权与实现自由

管理员只写 suite/plan；执行器只追加自己的结果；归集与评分器只写本轮报告；发布责任方独占决定和发布权限。包、候选材料为只读快照。审计材料保留至本次决定可追溯，具体归档/删除期由 U-5 定；不得在报告仍作为准入依据时静默删除其有效性证明。

文件、服务、队列、语言可替换，但须保持确定性切分、JSON 含义、计数、槽位唯一、盲测与完成提交语义。调用者必须能区分 input_invalid、blocked、incomplete、cancelled、completed；具体 HTTP 路由或 CLI 数字退出码属于适配契约，未供应前不得宣布目标 API 兼容。目标实现必须把错误与内容分开传递，不依赖解析人类报告文案。
