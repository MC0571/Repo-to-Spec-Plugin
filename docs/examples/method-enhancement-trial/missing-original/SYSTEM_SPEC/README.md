# Skill 触发评测与发布准入规格

版本：1.0（部分交付）。来源基准：874eb414e6414dd6d399222a7e3925206dfdb585。

目标是在既有产品的真实候选 Skill 环境中测量选择行为，将可信结果交给发布准入决策。套件已闭合用例、切分、盲测准备、来源评分、完整性判定和报告有效性规则，可据此独立实现这些部分。真实选择器适配及目标发布决策尚未闭合，不能宣称已具备可运行的发布门禁，也不能对任何目标包作出准入结论。

## 阅读顺序与权威

1. [评测规则](evaluation.md)：数据、切分、盲测、评分与来源 CLI 行为。
2. [运行与数据契约](runtime.md)：为真实评测补齐的执行、完整性、权限、报告和恢复设计。
3. [集成与未决](integration.md)：依赖、发布消费与需要目标方提供的输入。
4. [验收](acceptance.md)：已闭合部分的可观察测试和待解锁的集成验收。

正文规则为权威，验收不得新增阈值。`S-` 为恢复的来源规则；`R-` 为在真实评测约束内补齐的设计，不能冒称来源脚本已有这些能力；`U-` 为影响最终产品结果的未决项。完整性失败与逐例不匹配、评测完成与发布允许是不同结论。

## 范围与参与者

纳入：触发用例管理、固定切分、独立盲测要求、单选结果归集、目标二分类指标、兄弟选择诊断、报告有效性、真实选择器和发布流程的接入边界。目标方已有包和发布流程，但其契约未提供。

- Skill 维护者编写包、使用训练结果修复；不得接触仍用作保留集的逐例材料。
- 评测管理员冻结用例和运行条件、执行完整性审计，保管隐藏预期。
- 选择执行者只看真实选择所需的输入，返回选择；不阅答案，不修改包。
- 发布责任方提供预注册策略、消费有效报告、执行发布；评测器不代替其授权。

不吸收蒸馏、编译、Registry、网站、自动优化和安装发布实现。实际任务输出质量、路由入口内部到能力卡的可达性、全格式合规及统计非劣检验不在本次触发评测范围；触发通过不证明上述能力通过。若既有发布要求这些检查，其政策应在 U-4 中独立声明，不用触发评分替代。

无图形界面恢复范围；交互是任务、状态、报告和错误反馈。目标语言、平台、存储及界面未限定。实现可以替换语言与运行机制，但须满足可观察的数据与隔离约束；来源 Python CLI 是兼容参考，不是目标必装条件。实际宿主支持矩阵待 U-1 核实。

## 当前交付状态

可实施：`S-1` 至 `S-6` 的来源语义和 `R-1` 至 `R-6` 的平台无关核心设计。真实运行所需的配置值和提供者能力尚未供应，不能执行目标评测；发布策略 U-3/U-4 未定，不能将任何分数映射成批准或拒绝。未知项只阻塞对应集成和决定，不阻塞已闭合核心。
