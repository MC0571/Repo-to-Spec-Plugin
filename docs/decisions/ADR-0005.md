# ADR-0005：任务级持久化与可替换存储

> 基线：DB-20260928 · 状态：已采纳 · 类型：架构决策
> 本文承接现有愿景，不表示能力已经实现；变更与采纳规则见文档入口。


## 状态

2026-09-28 由维护者采纳；依据与适用范围见 [M0 采纳记录](../reviews/M0-ADOPTION.md)。后续替代时保留历史并指向新 ADR。

## 背景

愿景需要恢复与按需更新，却未决定数据库、事件系统或运行语言。

## 决策

采纳任务状态的单一权威、明确修订与冲突检测、一致恢复、可重建索引及内部/公开分离。任务级文件与检查点指针是 [OD02](OPEN-DECISIONS.md) 的优先实验方案；具体编码和提交机制须经崩溃、并发与平台验证后决定，并保留替换存储的合同。

## 替代方案与取舍

仅聊天会丢状态；直接建通用知识平台会放大维护成本。

## 后果与验证

必须验证崩溃、并发与平台语义；不能假设多文件写入天然事务化。

## 重新评估条件

若真实任务规模、并发或恢复实验无法满足要求，通过新 ADR 引入合适存储，不维护永久禁用数据库规则。
