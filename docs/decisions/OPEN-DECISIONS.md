## 决策记录要求

每次结果写明所比较方案、真实实验条件、适用范围、代价、受影响合同与回归。结论不成立时允许回到更早设计修订；不得为了保住里程碑日期制造“已经决定”。

在以上工程选择未批准前，后续代码可以在任务分支验证方案，但不能发布稳定接口、创建第二套权威状态或在 README 宣称正式支持。实验是目标方案的验证工具，不是另建一个与最终边界相冲突的临时产品。
