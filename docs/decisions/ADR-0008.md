# ADR-0008：可移植分发与薄宿主适配

> 基线：DB-20260928 · 状态：待评审提案 · 类型：架构决策提案
> 本文承接现有愿景，不表示能力已经实现；变更与采纳规则见文档入口。


## 状态

待评审提案。本文解释建议如何落实已有原则，不声称维护者已经批准该具体机制。接受后需记录评审依据；替代时保留历史并指向新 ADR。

## 背景

现有 CONTRIBUTING 已选 Agent Plugins 与 Agent Skills；不应再创建重复规则入口。

## 决策提案

遵循所声明标准版本；发布包纳入同一来源的技能与合同，客户端适配仅处理宿主差异，不复制核心交付流程。

## 替代方案与取舍

每客户端维护独立插件业务会漂移；只做指向开发仓库的适配器可能不满足自包含分发与路径边界。

## 后果与验证

标准校验与宿主真实加载分别验证；标准 Working Draft 与客户端支持不能混为一谈。

## 重新评估条件

目标客户端不支持必要规范时，记录真实限制并评审受控兼容输出，不静默假装支持。
