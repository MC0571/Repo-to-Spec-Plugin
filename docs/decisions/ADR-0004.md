# ADR-0004：原生基线与可选能力增强

> 基线：DB-20260928 · 状态：待评审提案 · 类型：架构决策提案
> 本文承接现有愿景，不表示能力已经实现；变更与采纳规则见文档入口。


## 状态

待评审提案。本文解释建议如何落实已有原则，不声称维护者已经批准该具体机制。接受后需记录评审依据；替代时保留历史并指向新 ADR。

## 背景

现有愿景拒绝让特定外部理解工具成为前提，但允许必要产品环境构成输入条件。

## 决策提案

能力合同以操作语义为中心，保留原生调查方法；外部 Provider 显式发现、授权、标准化与降级。

## 替代方案与取舍

围绕工具品牌拆架构带来绑定；声称原生模式能无条件替代所有真实观察会导致编造。

## 后果与验证

必须保留工具限制、版本、部分结果和缺输入阻塞；原生/增强对照验证同一范围。

## 重新评估条件

有实际质量或成本瓶颈再增加 Provider，不能仅因工具存在就改变核心交付。
