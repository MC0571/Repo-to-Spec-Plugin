## 2. 实际检查范围

既有命令为 `python3 scripts/ci_check.py` 和 `python3 scripts/ci_check.py --self-test`。检查器涉及 PR 标题语法、差异空白、已跟踪的敏感文件名及 Markdown 本地链接，并有内置自检。

它不验证产品行为、体系完整性、盲交接、正式 Schema 或宿主加载。敏感文件名检查也不是秘密内容扫描。仓库目前没有固定产品运行语言、包管理器或 build/test 工具链；存在 Python CI 脚本不能被解释为已经决定产品技术栈。
