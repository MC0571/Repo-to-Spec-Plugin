# 验收场景

下面的树表示输入内容；命令名称由实现者选择。断言关注行为和退出状态，不要求逐字复制输出文案。

| 场景 | 前置文件和操作 | 必须观察到的结果 |
| --- | --- | --- |
| A1 有效包 | `demo/SKILL.md` 有 `name: demo`、非空 `description` 和指向 `references/guide.md` 的 Markdown 行内链接；目标文件存在且均为 UTF-8。校验 `demo/`。 | 退出 `0`；一项技能入口、两份 Markdown、零错误/警告。 |
| A2 缺引用 | 从 A1 删除 `references/guide.md` 再校验。 | 退出 `1`；错误指向 `SKILL.md` 和缺失目标；其余可读文件仍被扫描。 |
| A3 缺描述 | `SKILL.md` 的 frontmatter 只有有效 `name`。 | 退出 `1`；报告缺少非空 `description`。 |
| A4 警告可见 | `demo/SKILL.md` 的 `name` 变为另一个合法名称，其余有效。 | 退出 `0`；至少一项名称与目录不符的警告，且错误数为零。调用方仍可按自身标准另行阻断发布。 |
| A5 编码错误 | 在根目录另加无法按 UTF-8 解码的 `.md`；有效 Skill 保持。 | 退出 `1`；报告该文件编码错误，有效 Skill 仍计入扫描并检查。 |
| A6 部分输入失败 | 同次传入一个不存在目录和 A1 的有效目录。 | 退出 `1`；报告不存在目录；有效目录仍完成扫描。 |
| A7 无技能入口 | 传入仅含 UTF-8 普通 Markdown 的目录。 | 退出 `0`；技能入口数为零，不能把此结果解释为可安装技能包。 |
| A8 用法错误 | 不传目录调用。 | 显示用法，退出 `2`；不声称完成扫描。 |
| A9 引用边界 | Markdown 中有 `https://example.com/references/missing.md`、`/tmp/assets/missing.png`、纯锚点和指向存在文件的相对路径。 | URL 和绝对路径中的片段不重新按裸路径报错；纯锚点与存在的相对目标也不触发缺失错误。校验通过不证明 URL 可达或路径在包内。 |
| A10 引用识别边界 | 加入指向 `guide/missing.md` 且含标题参数的 Markdown 链接、代码块中的 `references/missing.md`、`assets/*.png` 和句末 `references/a.md。`，其中 `a.md` 存在。 | 带标题的链接与通配符不因目标缺失报错；代码块中缺失的裸路径报错；句末标点不成为路径的一部分。 |
| A11 符号链接 | 传入目录本身是指向有效目录的链接；其内部另有指向另一目录的链接，以及指向根目录外一份有效 Markdown 的文件链接。 | 按传入目录链接的目标扫描；不沿内部目录链接递归；扫描文件链接一次。文件链接不可读取时非零退出，不声称已有完整扫描报告。 |
| A12 重复输入与统计 | 同一有效目录连续作为两个输入；另在其子目录中放一份无效 UTF-8 的 `SKILL.md`。 | 正常文件按两次扫描计数/报告；无效 UTF-8 文件计入 Markdown 数和编码错误，不计入已检查的技能入口数。 |
| A13 frontmatter 标记边界 | `demo/SKILL.md` 分别使用开头 `---name: demo` 或结尾 `---suffix`，其余 YAML 元数据有效；再试不以 `---` 开始或完全没有后续 `\n---` 的文件。 | 前两种均退出 `0`，后两种报告 frontmatter 错误并退出 `1`；这里的 `0` 不能替代完整 Agent Skills 格式检查。 |

发布集成还需做自己的完整标准与宿主加载检查。A1–A13 只验收本静态校验能力。
