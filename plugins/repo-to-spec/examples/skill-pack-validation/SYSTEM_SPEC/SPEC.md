# 行为与技术规格

## 输入、发现和只读约束

调用方传入一个或多个本地目录路径。未传入目录时，显示用法并以 `2` 退出。传入目录本身可以是指向目录的符号链接，按其目标扫描；在该目录内部递归扫描 `.md` 文件。文件名精确为 `SKILL.md` 的文件作为技能入口，其父目录代表该技能。扫描不进入遍历时发现的目录符号链接，避免循环和意外扩展范围；文件名以 `.md` 结尾的文件符号链接作为文件读取，包括指向根目录外的目标。悬空或不可读取的文件符号链接按读取失败处理。

多个目录按请求中的顺序分别扫描并合并结果；重复传同一目录、或同时传父目录与子目录时，重复发现的文件按扫描次数重复计数和报告，不做全局去重。每个目录内部的文件问题应以稳定顺序输出，方便比较两次检查。

输入目录不存在或不是目录时记录输入错误，并继续检查其他目录。扫描不写入或修改待检查目录，不访问网络，不执行文件内容。无法解码的 Markdown 计入 Markdown 文件数并记编码错误，但不计入已检查的技能入口数。其他文件系统读取失败使本次检查失败，可停止扫描，不保证完整总结；调用方须修复读取条件并重跑。扫描结果只适用于当次读取到的文件快照；调用方并发修改目录时须重跑。

## 技能入口

每个可读 `SKILL.md` 必须以三个连字符 `---` 开始，并在其后出现换行加三个连字符 `\n---` 作为结束标记；两处连字符不要求独占一行，结束标记后的同一行文本不属于待解析元数据。两标记之间的内容须能解析为 YAML 映射。frontmatter 缺失、无法解析或不是映射时记错误。映射中 `name` 和 `description` 必须是非空字符串；缺失、空白或其他类型记错误。只需解析元数据，不解释正文指令。此有限检查不证明符合完整 Agent Skills 标准。

`name` 建议首字符为小写拉丁字母或数字，其后只用小写拉丁字母、数字或连字符。风格不符或与父目录名称不同，分别记警告；警告本身不使本校验失败。`description` 内容质量不由该静态检查器判断。该严重级别是本能力的行为，不表示宿主或 Agent Skills 标准接受这些差异。

## Markdown 编码与引用

所有发现的 `.md` 文件必须能按 UTF-8 解码；不能解码时记错误，并跳过该文件的后续文本检查。对可读 Markdown，只识别以下有限形式，不宣称覆盖完整 Markdown 语法：

- 行内链接或图片的 `](目标)`，其中目标是没有空白和 `)` 的连续路径，可在末尾带 `#锚点`；带链接标题或空格的形式不由此规则识别。
- 文本中以 `references/` 或 `assets/` 起始、后接字母/数字/下划线/连字符/点/斜线并以扩展名结尾的裸路径。其前一字符不得是字母、数字、下划线、`/` 或 `(`，因此 URL、绝对路径和其他路径中的同名片段不会被再次解析为裸路径。反引号和围栏代码块中的独立裸路径也检查；`*` 等通配符不属于目标。

引用带有锚点时，以锚点前的路径找文件；纯锚点不要求额外文件。相对引用按所在 Markdown 文件的目录解析。相同文件中的同一目标只报告一次缺失。末尾句号不是裸路径的一部分。

HTTP(S)、`mailto:` 和绝对路径不做存在性检查。可识别的相对引用目标不存在时记错误。此规则只检验存在，不读取目标内容、不证明链接语义有效，也不限制相对路径越过传入目录；需要包内路径隔离的发布者必须另设检查。未识别的其他 Markdown 写法不应被声称已验证。

## 反馈、状态与技术边界

正常完成扫描时，每项问题至少包含严重级别、类别、发生文件及可定位的目标或字段；结束时显示 Markdown 文件数、技能入口数、错误数、警告数。可用命令输出呈现技能入口的大小概况（行数、UTF-8 字节数），用于人工检查，不设通过阈值。错误与警告需要可区分；输入、编码、元数据或引用错误不得隐藏其他可检查文件的问题。文件系统读取失败遵循前述可中止规则。

没有错误时退出 `0`，即使有警告或零个技能入口；有任意输入、编码、frontmatter 或引用错误时退出 `1`。文件系统读取失败也非零退出，但如上所述不保证完整总结。用法错误退出 `2`。调用方不得把 `0` 解读成包质量、标准合规或宿主加载已获证明。

实现需要把目录发现、解析和报告分开，使编码、元数据或引用错误不终止全局检查；文件系统读取失败可以中止。扫描不产生持久状态。YAML 解析必须按数据处理，不执行自定义对象。可使用任何语言和库满足这些结果；接口可包装成目标产品自己的命令。性能只要求能处理声明支持的本地包，未从材料恢复固定时间或内存目标，不得伪造数值承诺。

## 人机交互

唯一的人机界面是命令行报告。正常完成扫描时，成功给出扫描数量和 `0 errors` 等清楚的总结，失败在总结前列出每个已发现错误；警告须显式标成非阻断。路径应指向实际发生问题的文件；运行中无需交互确认。输入目录为空、只有普通 Markdown、只有警告、某文件编码损坏和多个根目录部分失败时，均提供完整总结和对应退出码。文件系统读取失败时可中止且不保证完整总结。
