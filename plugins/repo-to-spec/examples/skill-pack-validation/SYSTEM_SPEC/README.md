# Skill 包静态校验规格

## 目标与范围

为制作或发布 Agent Skill 包的人提供一个本地、只读的预检查：发现技能入口元数据、Markdown 编码和本地引用中的可确定错误，列出问题及扫描概况，让发布流程决定是否继续。该能力可独立嵌入另一个产品；不要求采用来源产品的内容蒸馏、编译、更新或评测体系。

本套件规定静态校验的输入、输出、规则、失败行为及验收。使用者包括手动检查包的作者，以及在发布前调用检查器的自动化流程。适用对象是本地目录中的 `SKILL.md` 和 Markdown 文件。无图形界面；命令输出是用户反馈。文档未规定运行语言、YAML 库、代码目录或命令名称。

阅读顺序：[行为与技术规格](SPEC.md) → [验收场景](ACCEPTANCE.md)。两者均为规范性内容；样例命令名仅表示命令接口，不限定实际可执行文件名。冲突时以行为与技术规格为准，并修正验收样例。

## 选择性吸收的依赖处置

| 必要依赖 | 处置与边界 |
| --- | --- |
| 本地文件访问 | 由目标环境提供一个或多个可读目录及其中的文件。读不到目录或文件按输入/读取错误报告。 |
| YAML frontmatter 解析 | 纳入本能力的语义；实现者可选解析器，但不得执行 YAML 中的代码或自定义对象构造。 |
| 发布流程 | 由目标环境提供。它依据退出状态决定是否发布；本能力不负责构建、复制或发布。 |
| Agent Skills 的完整标准符合性 | 由目标环境另行验证。本能力的警告不会自动成为阻断；校验通过不能宣称符合任何版本的完整标准。 |

若目标环境需要禁止引用越出包根目录，应在自己的发布门增加边界检查；本能力仅检查所识别引用的目标是否存在。这个限制不能作为安全隔离保证。

## 排除项与状态

不检查技能正文的质量、触发效果、语义正确性、文件许可证、工具权限、外部 URL 的可达性或宿主能否加载。没有有效材料表明这些属于本次能力。本套件可直接用于实现这里声明的静态校验；它不代表上述排除项已经通过检查。
