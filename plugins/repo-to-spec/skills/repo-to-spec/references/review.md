# 规格审查与交接

## 适用、输入和两种不同的检查

每完成一个能力草案，以及准备交付整个声明范围时使用。输入是请求/获准改动、参考版本、套件外调查记录、候选 `SYSTEM_SPEC/` 和验收场景。审查记录必须标明候选版本、检查者能看到的材料、实际操作和结论范围。

- **对照来源核对忠实性**：检查者可读参考仓库、测试、运行证据和调查记录，问规格是否错误、遗漏或未经批准改变了目标产品。它不能单独证明套件自包含。
- **脱离来源检查可实施性**：未参与作者工作的人只拿请求范围与正式 `SYSTEM_SPEC/`，不看仓库/调查笔记，问能否作出同一产品、体验和技术决定并写验收。它不能单独证明规格忠于来源。

同一个人做两项只能叫作者自检或同源审查；如声称“独立消费”，须记录信息隔离和接收者实际问题。代码实现、用户验收或真实宿主运行是更强且不同的证据，不得用文档审读冒充。

## 对照来源：操作与分支

1. 从请求逐项列声明结果、排除、用户批准的变化。沿每项结果的入口、正常/异常场景、共享规则及传递依赖，在来源中找至少一条支持链和相应反例；用测试与受控运行核对关键分支。把“没有看到”与“证实不存在”分开。
2. 逐项比较规格：前置、默认、状态、错误、权限、配置、数据/接口、视觉与运行边界。来源与规格不同先查版本、配置、角色、平台；若确属产品变化，找用户批准；若是为了闭合缺口的推导设计，写出所满足的已知约束和未验证部分。
3. 专查实现解耦：原库/语言/平台、调查机条件是否被升为目标要求；外部兼容语义是否反而被删掉。来源测试通过只证明其覆盖路径，不能证明外部标准或其他运行环境。
4. 发现错误时先改正式规则、验收及受影响的依赖，再补查/补跑相关场景；来源仍不充分且结果重要时保留未决，候选不能标最终。记录 `结论｜来源与条件｜性质（事实/推导/获准改动/未决）｜修订`，源码定位只放套件外。

## 脱离来源：操作与分支

1. 接收者只读正式套件，从入口找到范围、支持环境、术语、权威规则与验收；复述一条正常、一条失败和一条恢复路径。对 UI 任务还描述界面状态、反馈、视觉和键盘路径。
2. 要求其回答“给定输入/角色/状态会发生什么，如何验证”，并列出所有必须自行决定的产品结果、暗含外部依赖、相互冲突规则和无法写出的验收。把“实现可自行选择的机制”与“规格漏定的结果”分开。
3. 从验收反查规则、体验、数据、接口和必要技术约束；从重要规则正查至少一个验收。核对状态词汇是否覆盖所有声称会输出的状态，逐例“不匹配”和整轮“未通过”是否被阈值明确连接，验收示例有没有暗中固定正文尚未决定的策略。报告若用于后续决定，检查所有会使其失效的输入是否与消费条件一致；多目标时检查包级聚合。保留集/秘密的逐例反馈不能同时向调优者开放又声称仍保密。格式、链接或模板检查只辅助发现结构问题。
4. 若接收者需要回查源码、内部符号或作者口头解释，修订正式套件并让其只看修订后套件复查。若材料所限无法回答重要问题，保留草案和阻塞，不把空白称作实现自由。

## 完整示例：预检查规格的两轴复核

在本地 Skill 包预检查样例中，来源侧核对发现：原始生成把调查时使用的 Python/PyYAML 写成了目标必装；来源只证明解析语义，未证明新实现必须采用该运行时。修订规则为“安全加载并保持特定 YAML 类型、错误与诊断结果”，语言/库可替换，并同步改验收。该修订属于**评审后改动**，不倒写为原始生成结果；修订后若仅重新安装、未完整再生成，应保留这一验证限制。

独立接收者随后只拿正式套件，按“合法包 → 缺引用 → 读取失败 → 重跑”推导输出。其首轮若问“文件符号链接的相对引用以链接还是目标位置为基准”，这属于可实施性缺口；作者须回来源定位该行为或作有依据的设计决定，在正式规则和正反验收中定值。接收者复查修订稿能写出同样验收，才可记该缺口已关闭。即使两轴均通过，也只能称该范围/版本被审过，不能宣称目标检查器已实现或所有 UI 产品均已验证。

记录可写：`候选 A：来源核对发现运行依赖误判；候选 B：修正规则与验收；接收者只读 B，指出符号链接基准缺口；候选 C：补证修订并复查。目标实现测试未运行。` 这让原始、修订与未验证项不会混在“通过”二字里。

**容易做错**：作者拿着源码和自己的笔记“模拟陌生开发者”，然后记为独立消费通过；或只跑 Markdown 链接检查就宣布规格完整。另一个错误是接收者能实现出某一种行为，就认为它忠于来源——接收者从未看来源，无法作这个判断。

## 完成状态

最终套件须满足声明范围内无已知影响独立实施的重要未知、必要依赖闭合、作者自检完成；来源核对和独立消费实际做了多少分别报告。缺材料、运行条件或关键产品决定时，标草案/阻塞，列具体缺口、影响、已完成部分与下一项可回答的调查。一次样例仅支持该场景，不外推为所有产品类型可用。
